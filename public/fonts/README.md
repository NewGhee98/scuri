# Scuri text fonts

Downloaded from the official [Google Fonts repository](https://github.com/google/fonts) on 2026-09-25:

- [Cinzel](https://github.com/google/fonts/tree/main/ofl/cinzel): variable weight, normal only.
- [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond): variable weight, normal and italic.
- [Inter](https://github.com/google/fonts/tree/main/ofl/inter): variable weight, normal and italic.

Original TTF files are unmodified. Corresponding OFL licence notices are included here. Stable application family aliases keep canvas font loading deterministic. Fonts load on demand from the app's own origin; there are no runtime Google Fonts requests. Increment asset filename versions when updating bytes because the app worker caches static resources.
